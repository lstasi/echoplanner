# API Interface

## Overview

The API interface provides RESTful endpoints for external integrations and web interfaces. Built with FastAPI for automatic documentation and type safety.

## Endpoint Categories

### Events API
- CRUD operations for calendar events
- Event filtering and search
- Bulk operations and exports

### Family Management API
- Family member registration and management
- Role-based access control
- Preference management

### Email Processing API
- Trigger manual email processing
- Processing status and monitoring
- Configuration management

## Features

- Automatic OpenAPI documentation
- Request/response validation
- Authentication and authorization
- Rate limiting and security headers
